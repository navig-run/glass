# Changelog

## 0.2.0

First public release.

- Image engine: PNG, JPEG, WebP, GIF, BMP, TIFF, ICO, AVIF, HEIC, JXL; ICC colour management, EXIF orientation, animated GIF/WebP, transparency checkerboard.
- Exact-size window: the client area matches the image pixel for pixel.
- Frosted chrome with header and footer, zoom control, folder counter.
- Selection tool: Shift+drag marquee, copy / zoom to selection.
- Rotate, copy, delete, context menu, folder navigation, single-instance handoff.
- Peek: global Space hotkey previews the file selected in Explorer (7-9 ms).
- Document engine: PDF page view with keyboard paging and asynchronous rendering.
- Video engine: poster frame via Media Foundation.
- Audio engine: codec / sample rate / channels / bitrate card.
- Portable install and uninstall scripts; per-user, no admin, no default-app changes.
